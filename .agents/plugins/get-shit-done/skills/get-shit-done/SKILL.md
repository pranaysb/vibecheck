# Get Shit Done (GSD) Engine

The **Get Shit Done (GSD)** engine is Antigravity's high-velocity execution protocol for transforming bloated prototypes into lean, robust, production-grade applications.

---

## The 5 Core GSD Principles

### 1. Kill Verification Theater & Synthetic Bloat
- No fake databases, no phantom mock arrays (`const FAKE_ITEMS = [...]`), no unbacked marketing metrics.
- If a feature exists in the UI, it must be powered by real data, real API execution, and real user flows. If it isn't real, **cut it**.

### 2. Radical Simplification Over Feature Sprawl
- 1 feature that works reliably and solves an urgent problem is 100x more valuable than 20 half-baked dummy routes.
- Eliminate dead routes, unneeded forms, fake role switchers, and unearned compliance claims. Focus on the core value loop.

### 3. Bias to Action & Deep Iteration
- Do not spend turns endlessly speculating or writing long essays when code can be written, tested, and verified.
- Execute changes atomically: Plan -> Code -> Local Build / Test -> Deploy -> Empirical Verification.

### 4. Empirical Ground-Truth Verification
- Never declare a task complete based on a code edit alone.
- Test actual endpoints with `curl`, check runtime logs, inspect build outputs (`npm run build`), and verify live responses.
- If an assertion fails, diagnose the real root cause and fix it immediately.

### 5. High-Caliber Craft & Aesthetic Rigor
- Simple does not mean ugly. Clean typography, consistent design systems (e.g. Linear/Stripe aesthetic), crisp contrast, responsive viewports, and zero layout bugs.
